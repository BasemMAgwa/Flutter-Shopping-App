# Flutter Shopping App

A beginner-friendly, bilingual shopping app.

## Features

- Validated sign-up form with inline error messages
- Smooth fade transition to the shopping screen
- Responsive product carousel and two-column product grid
- Add-to-cart feedback using a SnackBar
- Five-item hot offers list
- English and Arabic localization using `easy_localization`
- Local Suwannaphum font and a mix of asset/network images

## Run the project

```sh
flutter pub get
flutter run
```

The local product photo comes from Unsplash, and Suwannaphum is distributed by Google Fonts.
